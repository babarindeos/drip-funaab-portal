# Updating the live DRIP portal (changes of 24 Oct 2026)

This update contains: restyled public pages, sign-in and staff profile; password reset;
the IBR / Conference-Workshop split on the homepage; an admin Maintenance page to clear caches; the new email design with the crest;
safe photo/signature uploads and login limits. **No database migration is needed.**

The zip `drip-update-2026-10-24-fixed.zip` holds ONLY the changed files, in their folders.

## 1. Before you start (5 minutes)
1. Pick a quiet time (evening or weekend): the portal is in use.
2. **Back up** the live site:
   - Download a copy of the live project folder (at least `app`, `config`, `resources`, `routes`, `public/css`, `public/build`).
   - Export the database (phpMyAdmin > Export, or `mysqldump`) for BOTH `drip_proposals` and `drip_conference`.
3. Check that the live site already has the earlier batches (Conference module, Eligibility, Restyle A and B).
   Quick test: the live admin dashboard shows the "Call for Proposals" and "Conference Grants" cards.
   If it does not, stop and upload the whole project instead (ask before doing this).

## 2. Put the site in maintenance mode (optional but recommended)
    php artisan down --refresh=15
Users see a "back soon" page for the few minutes of the update. (No SSH? skip this step.)

## 3. Upload the files
Unzip `drip-update-2026-10-24.zip` and copy everything into the live project folder,
**keeping the folders** (app/..., resources/..., etc.), replacing the existing files.
- cPanel: File Manager > upload the zip to the project folder > Extract (choose "overwrite").
- FTP (FileZilla): drag the unzipped folders onto the project folder, "Overwrite" when asked.
- SSH: `unzip -o drip-update-2026-10-24.zip -d /path/to/drip`

**Do NOT upload** from your computer: `.env`, `public/hot`, `storage/`, `vendor/`, `node_modules/`,
`bootstrap/cache/`, or the `_review_snapshot.tgz` / `_vendor_snapshot.tgz` files. They are not in the zip.

### Permissions (important)
Use `drip-update-2026-10-24-fixed.zip` (not the older zip): its folders are 755 and files 644, so the web
server can read them. If you already extracted the older zip, extracting over it may leave the old folders
locked. In cPanel File Manager set these to **755**: `public/css`, `public/build`, `public/build/assets`,
`public/images` (in `public_html` if that is your web folder), and the files inside them to **644**.
Then Ctrl+F5: the styling and the crest should be back.

## 4. Check the live .env (do not copy your local one)
Open the LIVE `.env` and make sure these are right:

    APP_ENV=production
    APP_DEBUG=false
    APP_URL=https://<your live address>
    DRIP_BASE_URL=https://<your live address>      <- links in emails (password reset, reviewers) use this
    DRIP_ADMIN_EMAIL=<the DRIP office inbox>        <- not a personal Gmail
    MAIL_MAILER / MAIL_HOST / MAIL_PORT / MAIL_USERNAME / MAIL_PASSWORD   <- the REAL mail server, not Mailtrap
    MAIL_FROM_ADDRESS=<an address on the FUNAAB domain>

Nothing new has to be added. (Optional: `MAIL_MARKDOWN_THEME=default` would bring back Laravel's plain email look.)

## 5. Clear the caches (required)
With SSH, in the project folder:

    php artisan optimize:clear
    php artisan config:cache
    php artisan route:cache
    php artisan view:cache
    php artisan up

`route:cache` used to fail on this project; this update fixes that, so it now works.
**No SSH?** Sign in as admin and open **/admin/maintenance** (also in the admin menu under your name >
Maintenance), then press **Run** on "Clear and rebuild everything". It runs the same commands and shows the result.
If that page will not open, delete the files in `bootstrap/cache/` except `.gitignore` with the file manager,
then open the page again. (Skip `php artisan up` if you did not use `down`.)

## 6. Check it works (10 minutes)
1. Homepage: "Latest calls for Research Proposals and Conferences/Workshops", cards labelled
   IBR Proposal / Conference/Workshop, the two links in the header. Press Ctrl+F5 if the old look shows.
2. "Call for Conference/Workshop" page opens and lists only conference calls.
3. Sign in as a staff member; open My profile, Edit details, Change password.
4. Sign out, "Forgot password?" with your own email: the email arrives with the crest, and the link
   opens the live site (if it opens 127.0.0.1, fix DRIP_BASE_URL and run step 5 again).
5. Register a test account: the new welcome email arrives. Delete the test account afterwards.
6. Admin: sign in at /admin.

## If something goes wrong
Run `php artisan down`, put back the backed-up folders from step 1, run step 5, then `php artisan up`.
The database is not changed by this update, so it never needs restoring for it.
